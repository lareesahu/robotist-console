Technical note

Each clip is joint-space animation derived from captured human performance, retargeted to a seventeen-degree-of-freedom humanoid and clamped to its mechanical limits. No mesh, texture or capture file is served by this page — the browser plays quaternions, which is the same stream a controller or simulator consumes.
