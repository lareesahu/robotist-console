# Robotist contributor instructions

## Mandatory brand reference

Before any website extension or UI change, read `docs/brand/BRAND_CENTER.md` and `docs/design/DESIGN_SYSTEM.md`. The homepage is the style authority. Reuse universal elements through their mapped owners; do not create route-specific replacement headers, footers, fonts or tracking. The current public typography overrides obsolete GRN Poppins declarations. Preserve named assets and compare the reference captures before completion.

A newer explicit user direction overrides this baseline. Record that change in the Brand Center and project documentation; never silently substitute an AI-selected style or completion standard. Existing distinct Eden/Edenne experiences are not permission to extend this corporate-page style into their worlds.

## Scoped UI workflow

For actual browser UI implementation or optimization, load the installed `ui-excellence` skill and follow Brand > Taste > Impeccable > Motion > Verify. Audit-only means inspect and report without bootstrapping or modifying product/quality state. Documentation-only, backend-only and operational work do not activate UI implementation stages. Read the skill's current request-scope rules.

No completion from a build or detector alone. Verify rendered behavior at relevant sizes, keyboard/focus, reduced motion and actual affected flows against the exact user brief. Historical captures and agent scores do not constitute human approval or verification of later edits.
